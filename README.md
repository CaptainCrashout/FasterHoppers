# Faster Hoppers

A Fabric mod for Minecraft 26.3 that adds a Super Hopper. Craft one from a
hopper and a block of iron, or find it in the Redstone creative tab. Super
Hoppers look like regular hoppers when placed and move items eight times faster.
Their inventory screen is titled "Super Hopper".

When Fabric Mod Menu is installed, Faster Hoppers appears with its own icon and
description in the mod list.

## Build

Use Java 25 and run `./gradlew build`. The mod jar is created in `build/libs`.
